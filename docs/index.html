How research works

  1. Ingest: extract text from uploaded files, chunk it, and optionally generate embeddings.
  2. Retrieve: search ready documents using lexical ranking and optional semantic similarity. Connected sources are queried on demand under user permissions.
  3. Ground: prepare bounded passages and ask the selected model to cite source IDs; without a model, return relevant excerpts.
  4. Inspect: show citations, retrieval traces and automated claim assessments. A valid citation is not proof of factual support.
  5. Reuse: save agent instructions and source selection, then invoke the agent from Home or Chat with an @mention.
Permission boundary: an agent's configured sources never automatically grant a caller access to those sources. Delegated source access requires a separately designed, explicit authorization system.

Known limitations

Current offline evaluation is synthetic, so it cannot establish real-world answer accuracy. Automated claim assessments are advisory. Long-running agents require the background worker, and connector credentials need independent deployment testing.
